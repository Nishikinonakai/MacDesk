# Bundled label font

Unmodified **Sarasa UI SC v1.0.42**, Regular, SemiBold and Bold, from [be5invis/Sarasa-Gothic](https://github.com/be5invis/Sarasa-Gothic/releases/tag/v1.0.42).

Sarasa UI uses proportional Inter-based Latin glyphs and Source Han Sans-based Chinese glyphs. The SC variant is used for the desktop label default; users can still select an installed font. Fonts are WPF resources and require no system installation. All three weights are original upstream files; no subsetting or synthetic bold is used for these weights.
